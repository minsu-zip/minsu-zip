### Hi there 👋
불편함을 해결하는 프론트엔드 개발자, **박민수**입니다.

WebView에서 생기는 사용자 불편과 반복 작업 같은 팀의 불편을 직접 찾아 고쳐온 4년차 프론트엔드 개발자입니다.

### 🙌 About Me

- **하이브리드 앱 문제 해결**: iOS WebView 세션 쿠키가 사라지는 원인을 찾아 로그인 이슈 99.7% 감소, WebView 부팅 30초 멈춤을 고쳐 Sentry 이슈 88% 감소
- **공통화와 자동화**: 40여 개 사내 서비스가 쓰는 디자인 시스템 패키지 구축, CI를 다시 설계해 배포 시간 51% 단축
- **제품 임팩트**: 간편결제 도입으로 결제 전환율 4.8% 향상, 거래 플로우의 PIN 입력 최대 9회 → 1회
- **지식 공유**: 트러블슈팅과 마이그레이션 기술 블로그 작성, 오픈소스 이슈에 해결책 공유, 신규 입사자 온보딩 운영, 외부 특강 6회

### 💼 Experience

**아이오트러스트(IoTrust)** | 2025.09 ~ 재직 중<br>
암호화폐 지갑 DCENT Wallet, DCENT Beam의 WebView 앱 개발

- Vue 2.7 → React 19 전환 참여: CSS 용량 83% 감소, Gzip 기준 번들 42% 감소, 테스트 12개 → 346개
- WebView 부팅 30초 멈춤 해결로 관련 Sentry 이슈 88% 감소
- DeFi 탭 신규 설계와 출시, 출시 3개월간 1.2만 명 조회
- 서명 횟수를 미리 계산하는 플로우 설계로 PIN 입력 최대 9회 → 1회
- CI를 바뀐 범위만 검사하도록 재설계하고 캐시를 적용해 배포 시간 51% 단축 (7.9분 → 3.9분)

**쏘카(SOCAR)** | 2023.01 ~ 2025.09<br>
쏘카 앱 안의 WebView 서비스, 사내 디자인 시스템 개발

- iOS 로그인 세션 이슈 해결: 로그인 관련 이슈 하루 246건 → 0.85건 (99.7% 감소)
- 디자인 시스템과 공통 모듈을 패키지로 만들어 40여 개 사내 서비스에서 재사용, 번들 용량 96.9% 감소
- 패스포트 구독 서비스에 간편결제를 도입해 결제 전환율 4.8% 향상 (A/B 테스트 검증)
